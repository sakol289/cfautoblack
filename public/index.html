กำลังโหลดสถานะ…

เปิด Challenge เมื่อ health path ของเว็บนั้นตอบ 5xx หรือเชื่อมต่อไม่ได้ 2 รอบติดกัน · ปิดเมื่อเว็บปกติและทราฟฟิกต่ำกว่า 6,000 req/min 3 รอบติดกัน โดยเปิดอย่างน้อย 2 นาที · ปิดสวิตช์นี้จะปิด Challenge ที่ระบบนี้ดูแลด้วย

Rule ID ของ custom rule ใน zone นี้ (ไม่ใช่ Zone ID) · รองรับ Interactive / JS / Managed Challenge · ระบบจะควบคุม expression และสถานะของกฎนี้ โดยเก็บสำเนากฎเดิมไว้ · ปิดโหมดอัตโนมัติก่อนเปลี่ยน ID ที่กำลังใช้งาน

ชื่อเว็บไม่ต้องใส่ https:// · Health path เช่น /probe หรือ /health ต้องตอบ 200 (เลือกตรวจ JSON ok:true ได้) · Challenge ครอบคลุม GET/HEAD ของเว็บนั้น ยกเว้น health path · ปิดการตรวจหรือลบเว็บแล้วบันทึก จะปลด Challenge ของเว็บนั้นด้วย
